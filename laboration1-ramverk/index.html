Ramverk för CSS är bibliotek som underlättar och skyndar på utvecklandet av webbplatser genom att erbjuda färdiga paket med CSS och ibland JavaScript kod. Därför kan man, istället för att manuellt designa en knapp med färg och haptik, helt enkelt leta upp en färdiggjord knapp i biblioteket och implementera den.

Det finns många likheter mellan dem CSS Ramverk jag har valt. Till att börja med är alla ramverk och erbjuder färdiga CSS-paket att implementera. Skillnaderna uppstår i arbetssättet. CSS Ramverk kan vara "Utility-based" eller komponentbaserade.

Ett utility-based ramverk handlar om att implementera små klasser som var och en gör en specifik sak, som man sedan staplar på varandra.
Komponentbaserade ramverk, och traditionell CSS, är baserade på större klasser i en CSS-fil som beskriver komponentens utseende eller funktion.
