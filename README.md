# CSS Frameworks

## [Netlify](https://laboration1-ramverk.netlify.app/)

This task was about creating a webpage with at least two subpages for one framework each. 
I chose three frameworks ranging from minimalistic to heavy; Milligram, Foundation and lastly Tailwind.

These frameworks offer different approaches to designing your webpage.

[Milligram](https://milligram.io/) is a minimalistic framework that offers minimal "help" with your designing. It makes buttons, forms and tables easier to create with built-in utilities to be used in HTML and CSS.

[Foundation](https://get.foundation/) went further than Milligram and offered more classes to directly manipulate the webpage in HTML, but still left some configuration up to the user to decide in CSS.

[Tailwind](https://tailwindcss.com/) makes everything work in HTML. The only things I wrote in CSS for the Tailwind subpage was overriding some colours to make them fit with my other subpages and the font. Otherwise I did all the styling in the HTML file.

All these three do come with standard or premade design choises, so some things must be overridden in some way if you'd want to choose your own font or colour for example.
